Веб-приложение для визуального формирования учебного расписания.

## Запуск

PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run.py
```

Затем открой:

http://127.0.0.1:5000/

Демо-учётные записи:

- Администратор: `admin` / `admin`
- Преподаватель: `teacher` / `teacher`

## Возможности финальной версии

- переключение между 1-й и 2-й учебной неделей;
- копирование расписания с одной недели на другую с проверкой конфликтов;
- фильтрация расписания по группе и поиску;
- поиск преподавателей;
- права администратора для изменения расписания и справочников;
- преподаватель работает только в режиме просмотра;
- все учебные группы отображаются снизу расписания, включая новые группы;
- тёмная тема;
- `.gitignore` для базы, виртуального окружения и служебных файлов.
