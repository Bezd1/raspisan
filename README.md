# Schedule App — готовая версия

Веб-приложение для визуального формирования учебного расписания.

## Стек
Python 3 + Flask + SQLite + HTML5 + CSS3 + Vanilla JavaScript.

## ВАЖНО
Открывай в VS Code папку проекта, в которой одновременно находятся:
- `run.py`
- `app`
- `templates`
- `static`

Структура должна выглядеть так:

schedule_app_ready/
  run.py
  requirements.txt
  app/
  templates/
    index.html
  static/
    style.css
    app.js

## Запуск

PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run.py
```

Затем открой:

http://127.0.0.1:5000/

Демо-учётные записи:

- Администратор: `admin` / `admin`
- Преподаватель: `teacher` / `teacher`

Справочники и расписание при запуске не заполняются тестовыми данными — их можно добавить через интерфейс.


## Исправления

В этой версии:
- добавлен маршрут `/`;
- Flask получает абсолютный путь к `templates`;
- Flask получает абсолютный путь к `static`;
- демо-учётные записи администратора и преподавателя создаются автоматически;
- справочники и расписание не заполняются тестовыми данными;
- SQLite создаётся автоматически;
- добавлена проверка `/health`.

Ошибка `TemplateNotFound: index.html`, возникшая в предыдущей версии, исправлена архитектурно: Flask больше не зависит от текущей рабочей директории.

## Возможности финальной версии

- переключение между 1-й и 2-й учебной неделей;
- копирование расписания с одной недели на другую с проверкой конфликтов;
- фильтрация расписания по группе и поиску;
- поиск преподавателей;
- права администратора для изменения расписания и справочников;
- преподаватель работает только в режиме просмотра;
- все учебные группы отображаются снизу расписания, включая новые группы;
- тёмная тема;
- `.gitignore` для базы, виртуального окружения и служебных файлов.
